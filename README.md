# 🕌 Islami App (Android Native)

Welcome to Islami App, your companion for spiritual growth and daily remembrance.  
This Android Native application is built using Kotlin and XML, providing essential Islamic features in a simple and user-friendly interface.

---

## ✨ Features:

- 📖 **Quran Kareem**  
  Read all Surahs of the Holy Quran with smooth navigation between chapters.

- 🕌 **Hadith Collection**  
  Browse a collection of authentic Hadiths with detailed view for each Hadith.

- 📿 **Tasbih Counter**  
  Digital Sebha to keep track of your daily Dhikr.

- 📻 **Quran Radio**  
  Listen to live Quran recitations using API integration.

- 🧭 **Tab-Based Navigation**  
  Easily switch between features using a clean tab layout.

---

## 🛠️ Technologies & Tools:

- 💻 **Kotlin** – Main programming language.
- 🎨 **XML** – UI design and layouts.
- 🔄 **Retrofit** – For handling API requests (Radio feature).
- 📡 **REST API** – Used for streaming Quran radio.
- 📂 **Local File Reading** – Quran and Hadith content stored locally.
- 🔁 **RecyclerView** – Efficient list rendering.
- 🧩 **Fragments** – Modular UI structure.
- 📑 **TabLayout + ViewPager** – Navigation between app sections.
